# Nightly Alpaca 1d moved to 17:00 ET

Date: **2026-09-13**

`/hot` Alpaca 1d was **Behind**: as_of **2026-09-10**, expected last close **2026-09-11**.

## Cause

CronRunner `channel_touch_nightly` was `0 23 * * 1-5` **local** (Israel). That is **16:00 ET cash close**. Friday 2026-09-11 23:00 local ran, exit 0 in ~8 min, scanned `as_of=2026-09-10`. TimescaleDB had **0** ALPACA 1d bars dated 2026-09-11 (2104 names on Thursday). Alpaca API on Sunday already had SPY **2026-09-11**. Weekend has no 1d retry (`1-5`).

Thursday’s run had the same lag (`as_of=2026-09-09`). The job was succeeding on the prior session.

## Fix

`crons/crontab.yaml`: **`0 17 * * 1-5`** with **`timezone: America/New_York`**. One hour after cash close so Alpaca daily can settle. Not 23:00 local (DST-fragile vs ET). `/hot` cadence copy updated. Manual catch-up remains `crons\channel_touch_nightly.bat` (bypasses `skip_if_ran_today`).
